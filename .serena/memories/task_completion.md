# Task Completion Checklist

Since this project has no test suite, linter, or formatter:

1. Verify the code compiles/is syntactically correct by inspection
2. Ensure TypeScript definitions in `index.d.ts` match any API changes
3. Ensure both iOS and Android implementations are in sync for any new features
4. Update version in `package.json` and `react-native-aes.podspec` if releasing
5. Commit with a descriptive message
